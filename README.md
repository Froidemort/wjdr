# Warhammer Sheet (M1+1)

Application offline-first de gestion de fiches Warhammer JDR V2.

Perimetre actuel:

- creer un personnage
- enregistrer en local
- rouvrir et modifier PV / Fortune / Destin
- exporter en JSON
- importer un JSON exporte depuis l'application

## Commandes

```bash
npm install
npm run dev
npm run build
```

## Tests

```bash
npm run test:unit
npm run test:e2e
npm test
```
