# Warhammer Sheet (M2)

Application offline-first de gestion de fiches Warhammer JDR V2.

Perimetre actuel:

- creer un personnage
- enregistrer en local
- rouvrir et modifier PV / Fortune / Destin
- exporter/importer JSON
- gerer un inventaire et l'equipement (quantite, poids, equipe)

## Commandes

```bash
npm install
npm run dev
npm run build
```

## Tests

```bash
npm run test:unit
npm run test:e2e
npm test
```
